Lathe (the `tradebot` repo) is a session-aware Forex bot for MetaTrader 5: scored signals, explicit risk gates, guarded orders and decision logs. It also ships Whetstone, a read-only reviewer for its trade journal.

**Pre-release.** First tagged release of a working project, for demonstration and controlled local use.

### What it does
- Session window, H1 regime, M15 setups and M5 triggers, with six setup patterns and signal scoring.
- Risk sizing, a daily-loss kill switch that survives restarts, hard ceilings on lot size and open positions.
- A trade journal and Whetstone: statistics, Markdown reports, historical tick replay and bounded single-rule research. It uses no LLM and never edits Lathe or places orders.

### Verified
- 439 automated tests pass in CI against a fake MT5; the full git history was scanned for secrets (none found).

### Known limits
- **Not financial advice.** It places real orders on a live account. The included strategy is a placeholder that proves the pipeline, not a recommendation. Use a demo account first.
- Never run against a real MT5 terminal in CI; broker behaviour is simulated.
- Windows-oriented launcher (`run.ps1`); Whetstone's replay needs optional dependencies.
